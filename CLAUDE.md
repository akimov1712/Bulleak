# CLAUDE.md — правила проекта «Трейдинг на Bybit с нуля»

Интерактивный сайт-курс по криптотрейдингу (Bybit, свинг-стиль). React + TypeScript, всё хранится в браузере.
Язык интерфейса, контента и документации — **русский**. Код, идентификаторы, коммиты — английский.

## Старт любой сессии
0. `git pull --ff-only` (работа может идти с двух ПК). Новый компьютер? Сначала `docs/ONBOARDING.md` (установка, запуск, контекст проекта).
1. Прочитать `docs/README.md` (карта ТЗ) и `docs/PROGRESS.md` (где остановились).
2. Взять **следующую невыполненную задачу** из текущего этапа `docs/05-tasks/stage-XX/`.
3. Перед кодом прочитать связанные документы, указанные в задаче (раздел «Контекст»).
4. После выполнения: отметить чекбокс в файле задачи, обновить `docs/PROGRESS.md`, сделать коммит (`npm run check && git commit …`) и **сразу `git push origin main`**.

## Жёсткие правила
- **Одна микрозадача = один коммит.** Формат: `type(scope): summary`, type ∈ feat|fix|content|docs|test|refactor|chore|style. Пример: `feat(quiz): add numeric question type`.
- **Definition of Done** — `docs/01-rules/definition-of-done.md`. Задача не закрыта, пока `npm run check` не зелёный.
- **Бизнес-логика — чистые функции** в `src/lib/**` с unit-тестами (XP, уровни, стрики, достижения, расчёты риска/ликвидации, симуляция сделок, метрики журнала). Компоненты только отображают.
- **TypeScript strict**, без `any`, без `// @ts-ignore`. Без `console.*` в коде приложения (`src/`) — ESLint `no-console: error`. CLI-скриптам в `scripts/` и e2e-тестам вывод в консоль разрешён (это их интерфейс).
- **Никаких секретов и ключей API** в репозитории. Приложение использует только публичные данные.
- **Контент**: только собственный текст, факты сверены с официальными источниками (Bybit Help Center / Bybit API docs / Investopedia и т.п.), источники записаны в бриф урока. Правила — `docs/01-rules/content-guidelines.md`.
- **Картинки**: свои SVG-схемы, графики из данных, SVG-макеты интерфейса Bybit (скриншотов нет), фото из любых источников (сайт личный — решение пользователя). Картинки скачиваются локально, список партии показывается пользователю перед скачиванием, источник пишется в `docs/03-content/credits.md`. Правила — `docs/01-rules/image-sourcing.md`.
- **Курс не даёт персональных инвестиционных рекомендаций и не обещает прибыль.** Дисклеймер обязателен.
- Репозиторий: `origin` = github.com/akimov1712/Bulleak, ветка `main`. **Каждый коммит пушится сразу** (разрешено пользователем 2026-09-27), теги этапов — тоже. Force-push, переписывание истории, создание новых репозиториев, деплой/публикация и прочие внешние действия — только с явного подтверждения пользователя.
- Работаем **по этапам**: в конце этапа — `/code-review`, фиксы, e2e, запись в `docs/06-qa/review-log.md`, демонстрация пользователю, ожидание фидбэка.

## Команды
```
npm run dev          # дев-сервер (Vite) — запускать через preview_start "web"
npm run check        # typecheck + lint + unit tests (обязательно перед коммитом)
npm run test         # vitest
npm run e2e          # playwright
npm run build        # production build
npm run data:fetch   # скачать исторические свечи Bybit в public/data/
```

## Окружение
Windows 10, Node 24 LTS, Vite 8, Vitest 5, git 2.39. `gh` CLI не установлен — понадобится на этапе 10.
- **`npm run e2e` и всё, что поднимает локальный сервер, запускать через PowerShell**, не через Bash: из Bash-песочницы подключения к localhost не проходят. Серверы слушают `127.0.0.1` явно.
- Дев-сервер для ручной проверки — только через `preview_start` (конфигурация `web` в `.claude/launch.json`). Она запускает Vite с `--host 0.0.0.0 --mode pane` (сайт доступен в локальной сети, например с ноутбука: `http://<IP-компьютера>:5173/`): панель не умеет WebSocket HMR, поэтому в режиме `pane` HMR выключен — после правок перезагружать страницу (`location.reload()`). Скриншоты панели в режиме эмуляции мобильного бывают неточными — проверять раскладку через `getBoundingClientRect` в `javascript_tool`.
- При записи файлов не использовать `\uXXXX`-экранирование в строках и регэкспах — инструмент записи превращает их в сами символы (например, неразрывный пробел). Использовать `\s` или `String.fromCharCode(...)`.
