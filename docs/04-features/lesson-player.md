# Плеер урока (`/lesson/:lessonId`)

## Вид
- Верх: хлебные крошки (Модуль → Урок), заголовок, «~12 мин», прогресс-бар чтения (липкий, по скроллу).
- Центр: MDX-контент в колонке ≤ 70ch; интерактивные блоки могут быть шире (до 900px).
- Справа (≥ 1280px): оглавление по h2 с подсветкой текущего раздела; термины урока.
- Низ: блок «Итоги» → большая кнопка «Пройти тест (N вопросов)» + «Назад к карте». Навигация «← предыдущий / следующий →».

## Поведение
- Урок считается **прочитанным**, когда пользователь доскроллил до блока «Итоги» (IntersectionObserver) и провёл на странице ≥ 60 с (или ≥ 30% оценочного времени, берём меньшее). Тогда: `markRead(lessonId)` → +10 XP (один раз).
- Таймер активного времени (`useLessonTimer`): считает секунды, только когда вкладка видима и была активность (скролл/клик/клавиша) за последние 60 с. Сохраняет в `lessons[id].timeSpentSec` и `activity[today].minutes` раз в 15 с и при уходе.
- Позиция скролла сохраняется в sessionStorage и восстанавливается.
- Кнопка теста активна всегда (можно сразу к тесту), но XP за чтение даётся только по правилу выше.
- Заблокированный урок → экран-заглушка (см. routing.md).
- Ошибка загрузки MDX → ErrorBoundary с кнопкой «Повторить».

## Критерии приёмки
- Все MDX-компоненты из content-pipeline.md отрисовываются в обеих темах.
- Прогресс-бар чтения и оглавление работают на длинном уроке.
- XP за чтение начисляется ровно один раз (компонентный тест с моками).
