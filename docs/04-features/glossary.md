# Глоссарий и шпаргалки

## Глоссарий (`/glossary`)
- Данные: `content/glossary.ts` — `Term { id, term, aliases[], short (1 предложение), full (2–5 предложений, markdown), category, related[], lessonId }`.
- Категории: Основы крипты, Биржа и ордера, График, Индикаторы, Фьючерсы, Риск, Психология, Стратегия.
- Страница: поиск (по term, aliases, short; без учёта регистра и «ё/е»), фильтр по категориям, алфавитный указатель А–Я / A–Z.
- Карточка термина: определение, связанные термины (чипы), «Изучается в уроке …» (ссылка; если урок закрыт — неактивна).
- Термины, ещё не пройденные по курсу, помечены «впереди», но доступны для чтения.
- Просмотр термина → `counters.glossaryViewed++` (для достижения).

## Шпаргалки (`/cheatsheets`)
Статичные карточки, открываются по мере прохождения модулей:
- Типы ордеров Bybit, Свечные паттерны (мини-SVG), Фигуры, Индикаторы: что показывают и ловушки, Формулы риска, Структура рынка, Эмоции и что с ними делать.
- **Чек-лист перед сделкой** (интерактивный, с галочками; сбрасывается): тренд старшего ТФ, уровень, сетап по стратегии, стоп за структурой, R:R ≥ 2, риск ≤ 1%, нет важных новостей, эмоционально спокоен, записал план в журнал.
- Кнопка «Печать» (print-стили).
