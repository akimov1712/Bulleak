# Настройки, экспорт, импорт (`/settings`)

## Настройки
- Профиль: имя (для приветствия и сертификата).
- Тема: Светлая / Тёмная / Как в системе.
- Цель дня: 20 / 50 / 100 / 150 XP.
- Звуки: вкл/выкл.
- Анимации: Как в системе / Включены / Минимум.
- Свободный режим: открыть все уроки (с предупреждением, что курс рассчитан на последовательное прохождение).

## Данные
- «Скачать резервную копию» → JSON (см. storage.md). После экспорта запоминается дата последнего бэкапа.
- «Восстановить из файла» → импорт с предпросмотром и подтверждением.
- «Сбросить весь прогресс» → ввод слова «СБРОС». Очищает localStorage-ключи и таблицы Dexie.
- Информация: версия приложения, объём занятых данных (оценка), дата последнего бэкапа.

## Критерии приёмки
- Экспорт → сброс → импорт возвращает идентичное состояние (e2e).
- Импорт битого файла/чужого JSON — понятная ошибка, данные не изменены (unit + e2e).
- Импорт файла старой версии схемы проходит миграцию.
