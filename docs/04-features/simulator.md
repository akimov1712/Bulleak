# Тренажёр (`/simulator`)

## Идея
Торговля на реальной истории Bybit «вслепую»: пользователь видит график до случайной (или заданной сценарием) точки, принимает решение, затем свечи воспроизводятся и сделка закрывается по SL/TP. Безопасная практика до тестнета.

## Режимы
1. **Сценарии** (`content/scenarios.ts`) — привязаны к урокам: заданный датасет, точка старта, подсказка задания («Найди пробой уровня и войди по ретесту»), разбор после сделки (что было «по учебнику»).
2. **Свободный режим** — выбор инструмента (BTC/ETH/SOL) и таймфрейма (1H/4H/1D), случайная точка старта (минимум 200 свечей истории перед ней и 150 после).

## Экран
- Слева/сверху: график (lightweight-charts), видимые свечи до точки старта; инструменты: горизонтальная линия, индикаторы (EMA 20/50/200, RSI, объём — переключатели).
- Панель сделки: Long / Short, вход — «по рынку» (цена закрытия последней свечи), Stop Loss, Take Profit (ввод числом или перетаскиванием линий на графике), риск % от баланса (0.5 / 1 / 2%, по умолчанию 1%), плечо (информационно, для расчёта маржи и ликвидации).
- Расчёт в реальном времени: размер позиции, R:R, потенциальный убыток/прибыль в $, цена ликвидации (при заданном плече); предупреждение, если ликвидация ближе стопа.
- Кнопка «Пропустить» (не входить) — тоже решение, прокручивает 20 свечей вперёд.
- Воспроизведение: скорость 1× / 4× / мгновенно, пауза, «закрыть вручную».
- Виртуальный баланс: старт $10 000, хранится отдельно, кнопка сброса.

## Логика (`lib/trading/simulate.ts`)
```
simulateTrade(candles, startIndex, order, maxBars) => { exitIndex, exitPrice, outcome, pnl, r, fees }
```
- Проверка по каждой следующей свече: для long — `low <= sl` → SL, `high >= tp` → TP; для short — наоборот.
- **Если в одной свече задеты и SL, и TP → считаем SL** (консервативно) и показываем пометку «неоднозначная свеча».
- Гэп через стоп (open за SL) → исполнение по open (проскальзывание).
- `maxBars` (по умолчанию 150) → `timeout`, закрытие по close.
- Комиссии: тейкер на вход и выход (значение из `lib/trading/fees.ts`, сверить с Bybit на этапе 5; по умолчанию 0.055% для perpetual).
- `r = pnl / riskAmount`, где `pnl` — после комиссий (грязный результат — `grossPnl`), `riskAmount = qty × |entry − sl|`.
- Гэп через тейк (open за TP) тоже исполняется по open — как рыночный ордер после срабатывания.
- Пошаговое воспроизведение: `startTrade` → `stepTrade` по свече → `closeManually` для ручного закрытия по close последней показанной свечи. Если данные кончились раньше `maxBars` — `timeout` по close последней свечи.
- Валидация: для long `sl < entry < tp`, для short `tp < entry < sl`; размер позиции > 0.

## Сохранение
Каждая сделка → `SimTrade` в Dexie; XP по gamification.md; счётчики для достижений.

## Критерии приёмки
- Unit-тесты `simulateTrade`: TP, SL, обе в одной свече, гэп, timeout, short-зеркало, комиссии.
- Сценарии загружаются по URL `/simulator/:id`.
- На мобильном график ≥ 320px высотой, панель — снизу листом.
