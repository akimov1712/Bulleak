# Журнал сделок (`/journal`)

## Назначение
Запись каждой сделки на демо/тестнете/реальном счёте Bybit для анализа своей стратегии (модули 10–12). Данные вводятся вручную (без API-ключей).

## Список
- Фильтры: счёт (demo/testnet/real/все), сетап, период, результат (+/−).
- Таблица на десктопе / карточки на мобильном: дата, символ, сторона (цветной бейдж), R, P&L, сетап, следовал ли плану.
- Верх: KPI-плитки (сделок, winrate, profit factor, средний R, матожидание, max drawdown), equity curve (в R и $).
- Разбивка по сетапам и по эмоциям («сделки в состоянии FOMO: winrate 20%») — ключевой инсайт для психологии.

## Форма сделки (`/journal/new`, `/journal/:id`)
Поля — см. `JournalTrade` в data-model.md. Разделы: Инструмент и счёт → Вход (цена, стоп, тейк, объём, плечо) → Выход (цена, дата, комиссии) → Разбор (сетап — выбор из своих + создание нового, таймфрейм, «следовал плану» да/нет, эмоция, заметки, теги).
- Расчёт P&L и R автоматически при заполненном выходе (`lib/journal/pnl.ts`).
- Можно сохранить открытую сделку (без выхода), закрыть позже.
- Удаление с подтверждением.
- Импорт CSV из Bybit — вне рамок (возможное улучшение).

## Метрики (`lib/journal/metrics.ts`)
winrate, profit factor `Σprofit/|Σloss|` (∞ если нет убытков → показывать «—»), avg R, expectancy, max drawdown (в R и %) по equity curve, лучшая/худшая серия, средняя длительность сделки, % сделок по плану.

## Критерии приёмки
- Unit-тесты метрик (пусто, только прибыльные, только убыточные, смешанные).
- Форма валидирует: стоп по правильную сторону от входа, qty > 0.
- Данные переживают перезагрузку и попадают в экспорт.
