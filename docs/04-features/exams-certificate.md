# Экзамены и сертификат

## Экзамен модуля (`/exam/:moduleId`)
- Пул 20–30 вопросов по всем урокам модуля (`modules/mXX/exam.ts`), в прохождение попадают 15 (стратифицированно по урокам).
- Порог 80%. Движок тот же, что для тестов уроков (quiz-engine.md), но объяснения показываются **в конце**, а не после каждого ответа.
- Провал → показать слабые уроки (по тегам) с кнопками «Повторить урок». Пересдача не раньше чем через 10 минут (таймер на экране), чтобы мотивировать повторение.
- Сдача → +150 XP, анимация, открывается следующий модуль.

## Финальный экзамен (`/exam/final`)
- Пул ≥ 60 вопросов по всему курсу, в прохождение — 40, порог 85%.
- Практическая часть: 3 сценария тренажёра, в которых нужно принять решение по своей стратегии (вход / пропуск, стоп, тейк); оценивается соблюдение риска ≤ 1% и R:R ≥ 1.5, а не результат сделки.
- Сдача → сертификат + достижение «Выпускник».

## Сертификат (`/certificate`)
- Красивая карточка (SVG/HTML): имя, название курса, дата, итоговый балл, уровень и титул, число часов, маскот, «уникальный» код (хэш от имени + даты).
- Кнопки: «Скачать PNG» (canvas-рендер `html-to-image`) и «Печать».
- Честная приписка: «Сертификат подтверждает прохождение персонального учебного курса».
