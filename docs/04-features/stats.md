# Статистика (`/stats`)

## Разделы (вкладки)
### Обучение
- KPI-плитки: всего XP, уровень, уроков пройдено / 62, среднее по тестам, время обучения (часы), текущий / лучший стрик.
- XP по дням — столбчатая диаграмма за 30 дней (переключатель 7/30/90).
- Календарь активности — тепловая карта за 6 месяцев (как GitHub), цвет по XP за день; тултип.
- Прогресс по модулям — горизонтальные бары (цвет модуля).
- Точность по темам (теги вопросов) — список с барами, 5 самых слабых тем выделены + ссылка на уроки для повторения.
- История тестов — таблица последних 20 попыток.

### Тренажёр
- Сделок, winrate, средний R, суммарный R, profit factor, лучшая/худшая сделка.
- Кривая баланса виртуального счёта (equity curve).
- Распределение R (гистограмма).

### Журнал (реальная/тестнет-торговля)
- Те же метрики, что на странице журнала, с фильтром по счёту (demo/testnet/real) — переиспользует `lib/journal/metrics.ts`.

## Правила
- Все агрегаты — чистые функции `lib/stats/*.ts` с тестами.
- Пустые состояния с маскотом и подсказкой, что сделать.
- Цвета графиков — токены, одинаковые в обеих темах по смыслу (bull/bear/xp).
