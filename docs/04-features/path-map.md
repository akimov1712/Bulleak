# Карта пути (`/path`)

## Назначение
Программа курса и прогресс по ней. С редизайна «Терминал» (2026-10-30) — не игровая тропа из кружков, а аккуратный список модулей с уроками (пользователь назвал прежний дизайн «любительским»).

## Вид
- Слева — карточки модулей: иконка в цвете модуля, «Модуль 02», название (ссылка на страницу модуля), «3 / 6» и тонкая полоса прогресса, кнопка «Уроки модуля N» (раскрыть/свернуть).
- Модуль с текущим уроком и начатые модули раскрыты; пройденные и закрытые свёрнуты до шапки.
- Урок — строка: значок статуса, номер «2.1» моноширинным, название, справа звёзды и минуты. Те же строки на странице модуля (с краткой целью урока).
- Статусы строки:
  - `locked` — серый замок; клик → тост «Урок пока закрыт».
  - `available` — зелёный значок «играть», ссылка на урок.
  - `read` — урок прочитан, тест не сдан: значок теста, ссылка ведёт на тест.
  - `completed` — зелёная галочка, 1–3 звезды по лучшему результату (80–89% ★, 90–99% ★★, 100% ★★★).
- Текущий урок подсвечен фоном и зелёной полосой слева, метка «Следующий урок» / «Остался тест».
- Последняя строка модуля — экзамен: «после уроков» / «15 вопросов · 80%» / «сдан · 92%».
- Справа (на телефоне — сверху) — карточка «Прогресс» (уроки, модули, кнопка «Продолжить · урок N.M») и карточка «Финальный экзамен» со ссылкой на сертификат после сдачи.
- При загрузке — автоскролл к текущему уроку.

## Правила разблокировки (`lib/progress/unlock.ts`)
- Урок 1 модуля 0 доступен всегда.
- Урок N доступен, если урок N−1 того же модуля `completed`.
- Первый урок модуля M доступен, если экзамен модуля M−1 сдан (для модуля 0, без экзамена — если все уроки модуля 0 completed).
- Экзамен модуля доступен, если все уроки модуля completed.
- Финальный экзамен — если сданы все экзамены модулей.
- `settings.freeMode = true` → всё доступно (уроки помечаются, достижения за «честное» прохождение не блокируются).

## Критерии приёмки
- Статусы корректны для любых комбинаций прогресса (unit-тесты `unlock.ts`).
- На 375px — одна колонка без горизонтального скролла, строки уроков ≥ 44px.
- Клавиатура: Tab по доступным урокам и кнопкам раскрытия модулей, Enter открывает урок.
