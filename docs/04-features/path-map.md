# Карта пути (`/path`)

## Назначение
Главный визуальный образ прогресса в стиле игровой карты: извилистая тропа из узлов-уроков, сгруппированных по модулям.

## Вид
- Модуль = секция с цветной шапкой (цвет модуля, иконка, название, «3/5 уроков», кнопка «Экзамен»).
- Узлы уроков — круглые кнопки 64–72px, расположенные зигзагом (смещение по X по синусоиде), соединены пунктирной линией.
- Состояния узла:
  - `locked` — серый, замок; клик → тост «Сначала пройди предыдущий урок».
  - `available` — цвет модуля, пульсирующее кольцо, над ним плашка «Начать» и маскот рядом (только у текущего урока).
  - `read` — урок прочитан, тест не сдан: цвет модуля, иконка теста.
  - `completed` — золотой/цветной с галочкой, 1–3 звезды по лучшему результату (80–89% ★, 90–99% ★★, 100% ★★★).
- Узел экзамена модуля — большой «сундук/кубок», открывается после завершения всех уроков модуля.
- Клик по доступному узлу → поповер: название, summary, минуты, кнопка «Начать»/«Повторить».
- При загрузке — автоскролл к текущему уроку.
- Финиш карты — «Финальный экзамен» и «Сертификат».

## Правила разблокировки (`lib/progress/unlock.ts`)
- Урок 1 модуля 0 доступен всегда.
- Урок N доступен, если урок N−1 того же модуля `completed`.
- Первый урок модуля M доступен, если экзамен модуля M−1 сдан (для модуля 0, без экзамена — если все уроки модуля 0 completed).
- Экзамен модуля доступен, если все уроки модуля completed.
- Финальный экзамен — если сданы все экзамены модулей.
- `settings.freeMode = true` → всё доступно (уроки помечаются, достижения за «честное» прохождение не блокируются).

## Критерии приёмки
- Статусы корректны для любых комбинаций прогресса (unit-тесты `unlock.ts`).
- На 375px карта в одну колонку без горизонтального скролла, узлы ≥ 56px.
- Клавиатура: Tab по доступным узлам, Enter открывает поповер.
