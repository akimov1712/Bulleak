# Движок тестов

## Поток
1. Экран старта: название, число вопросов, порог (80%), лучший результат, маскот. Кнопка «Начать».
2. Вопросы по одному. Сверху — прогресс-бар (сегменты: зелёный — верно, красный — неверно) и крестик «выйти» (с подтверждением).
3. Пользователь отвечает → кнопка «Проверить» → мгновенная обратная связь:
   - верно: зелёная плашка снизу, «Отлично!» + explanation (свёрнуто, можно раскрыть), звук/вибрация (если включено);
   - неверно: красная плашка, правильный ответ подсвечен, explanation раскрыто.
   → кнопка «Дальше».
4. Экран результата: процент, кольцо, звёзды, «верно N из M», полученный XP (анимация счёта), новые достижения, маскот (`cheering` или `sad`). Список ошибок с объяснениями. Кнопки: «Пересдать», «К следующему уроку» (если сдан), «Повторить урок».

## Типы вопросов (`features/quiz/questions/`)
| Тип | UI | Проверка |
|---|---|---|
| `single` | Карточки-варианты, клавиши 1–9 | `answer === correct` |
| `multi` | Карточки с чекбоксами, подсказка «выбери все верные» | множества равны (частичный ответ = неверно) |
| `truefalse` | Две большие кнопки «Верно / Неверно» | равенство |
| `numeric` | NumberInput с единицей; принимает `,` и `.` | `abs(x - correct) <= tolerance` |
| `chart-click` | CandleChart; клик ставит маркер (цена или свеча), можно переставить | цена в `[min,max]` или индекс свечи в `indices` |
| `match` | Два столбца, выбор пары кликом (слева → справа), на мобильном — селекты | все пары верны |
| `order` | Список с перетаскиванием + кнопки ↑↓ (для клавиатуры/мобайла) | порядок совпадает |

## Логика (`lib/quiz/`)
- `prepareQuiz(quiz, seed)`: если `sample` — выбрать `sample` вопросов (стратифицированно по тегам), перемешать вопросы и варианты (seeded RNG → воспроизводимо в тестах). `order` и `match` перемешиваются всегда.
- `gradeQuestion(q, answer): boolean`.
- `gradeQuiz(quiz, answers): QuizResult` (ratio, passed = ratio >= passRatio, perQuestion, теги).
- Вопрос считается верным **с первой попытки**; второго шанса внутри прохождения нет.

## Интеграция с прогрессом
`completeQuiz(result, now)` в progressStore → `lib/xp.ts` считает XP, `lib/achievements.ts` — новые достижения, `lib/streak.ts` — стрик. Запись в `quizAttempts`, обновление `lessons[id].quizBest/quizAttempts/completedAt`, `activity[today]`.

## Критерии приёмки
- Каждый тип вопроса: компонентный тест (правильный/неправильный ответ, клавиатура).
- Граница 80%: 8/10 — сдан, 7/10 — нет; 9/12 = 75% — нет, 10/12 — сдан.
- Выход из теста посреди — попытка не засчитывается.
