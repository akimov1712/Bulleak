# Калькуляторы (`/tools`)

Все формулы — `lib/trading/*.ts` с тестами. Каждый калькулятор — карточка: поля ввода слева, результат справа (крупно), пояснение «как считается» (раскрывающееся), кнопка «Сбросить». Значения полей запоминаются в localStorage (per-calc). Встраиваются в уроки через `<CalcEmbed id>`.

| id | Название | Входы | Выходы |
|---|---|---|---|
| `position` | Размер позиции | баланс, риск %, вход, стоп, (плечо) | риск $, объём в монетах и $, требуемая маржа, % расстояния до стопа |
| `liquidation` | Цена ликвидации | сторона, вход, плечо, режим маржи (isolated), MMR | цена ликвидации, расстояние % , предупреждение если стоп дальше ликвидации |
| `rr` | Риск / прибыль | вход, стоп, тейк(и) | R:R, требуемый winrate для безубыточности `1/(1+RR)` |
| `expectancy` | Матожидание | winrate, средний выигрыш R, средний проигрыш R, (сделок в месяц, риск %) | матожидание в R на сделку, ожидаемый результат за месяц в R и % |
| `fees` | Влияние комиссий | объём, maker/taker %, число сделок, funding % и число периодов | комиссия за сделку, в месяц, % от риска |
| `drawdown` | Просадка и восстановление | просадка % / серия убытков × риск % | нужный рост для восстановления `1/(1-d)-1`; просадка после N убыточных подряд |
| `compounding` | Сложный процент (реалистичный) | депозит, средний % в месяц, месяцев | кривая роста + предупреждение о нереалистичных ожиданиях |

## Формулы (сверить с Bybit Help Center на этапе 6)
- Размер позиции (в монетах): `qty = (balance * risk) / |entry - stop|`.
- Упрощённая ликвидация isolated (linear USDT perp), без учёта комиссий:
  long: `liq = entry * (1 - 1/lev + mmr)`, short: `liq = entry * (1 + 1/lev - mmr)`.
  В UI — пометка «приблизительно; точная цена — в интерфейсе Bybit».
- Безубыточный winrate: `1 / (1 + RR)`.
- Матожидание: `E = w * avgWinR - (1 - w) * avgLossR`.

## Валидация
- Некорректный ввод (стоп = вход, отрицательные, пустые) → результат «—» и подсказка, никакого NaN/Infinity.
- Разделители `,` и `.`.
