# Геймификация

## XP (`lib/gamification/xp.ts`)
| Действие | XP | Ограничение |
|---|---|---|
| Урок прочитан | +10 | один раз на урок |
| Тест урока сдан впервые | +50 | один раз |
| Бонус за результат при первой сдаче | 90–99% → +10, 100% → +25 | один раз |
| Улучшение лучшего результата при пересдаче | +5 | только если best вырос, макс. 3 раза на урок |
| Пересдача без улучшения | 0 | — |
| Экзамен модуля сдан впервые | +150 (+50 за 100%) | один раз |
| Финальный экзамен | +500 | один раз |
| Сделка в тренажёре завершена | +5, выигрыш по плану (TP) +5 | до 50 XP в день |
| Запись в журнале (закрытая сделка с заполненными полями) | +10 | до 30 XP в день |
| Первый запуск калькулятора каждого типа | +5 | один раз на тип |
| Выполнена цель дня | +20 | раз в день |
| Достижение | по таблице достижений (10–200) | один раз |

Вся XP-логика — чистые функции `(state, event, now) => { xpGained, reasons[] }` с тестами на каждое правило.

## Уровни (`lib/gamification/levels.ts`)
Порог уровня `L` (L ≥ 2): `xpFor(L) = round(60 * (L-1)^1.6)`, округлить до 10. 20 уровней. Всего XP за курс ≈ 62×(10+50+~10) + 12×170 + 500 + практика ≈ 7 000–9 000 → уровень 20 достижим к концу курса с практикой.
Ранги (каждые 2 уровня новый титул): 1–2 «Новичок», 3–4 «Наблюдатель», 5–6 «Ученик», 7–8 «Чартист», 9–10 «Аналитик», 11–12 «Риск-менеджер», 13–14 «Стратег», 15–16 «Свинг-трейдер», 17–18 «Профи», 19–20 «Мастер рынка».
Level up → полноэкранный модал с маскотом `cheering`, конфетти, новый титул.

## Стрик (`lib/gamification/streak.ts`)
- День активен, если за локальную дату заработано ≥ 1 XP.
- `current` растёт, если предыдущий активный день — вчера; если пропущен 1+ день: при наличии `freezes` — тратится заморозка за каждый пропущенный день (если хватает), иначе сброс до 1.
- Заморозки: +1 за каждые 7 дней стрика, максимум 2.
- UI: огонёк с числом в TopBar; на главной — неделя из 7 кружков. Пропуск без заморозок → мягкое сообщение маскота, без стыжения.

## Цель дня
Настраивается 20 / 50 / 100 / 150 XP (по умолчанию 50). Кольцо прогресса на главной. Выполнение → +20 XP и тост.

## Достижения
Список и условия — [../03-content/achievements-list.md](../03-content/achievements-list.md). Определения — `content/achievements.ts`, проверка — `lib/gamification/achievements.ts: evaluateAchievements()`; вызывается конвейером `lib/progress/applyEvent.ts` после каждого события. Разблокировка → тост с иконкой, редкостью, XP. Редкость: обычное / редкое / эпическое / легендарное (цвет рамки).

## Празднования
- Сдача теста: конфетти (сила зависит от звёзд).
- Level up, сдача экзамена, сертификат: большой модал.
- Всё отключается при `prefers-reduced-motion` / настройке.
