# Git-процесс

- Ветка `main`. До этапа 10 работаем локально; пуш на GitHub — только после подтверждения пользователя.
- **Одна микрозадача = один коммит.** Если задача большая — несколько коммитов, каждый проходит `npm run check`.
- Формат: `type(scope): summary` (английский, повелительное наклонение, ≤ 72 символа).
  - `feat` — функциональность, `fix` — баг, `content` — уроки/тесты/глоссарий, `docs` — ТЗ, `test`, `refactor`, `style`, `chore` — конфиги/зависимости.
  - scope — фича или модуль: `quiz`, `sim`, `store`, `m03`, `docs`.
- В теле коммита — номер задачи: `Task: T-203`.
- Последняя строка сообщения: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Не коммитить: `node_modules`, `dist`, `.env*`, отчёты playwright, временные файлы.
- В конце этапа — тег `stage-XX-done`.
