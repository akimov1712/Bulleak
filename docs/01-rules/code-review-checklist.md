# Чек-лист код-ревью (конец каждого этапа)

Сначала `/code-review` по диффу этапа, затем ручной проход по списку.

## Корректность
- Граничные случаи (пустые данные, деление на ноль, NaN/Infinity в калькуляторах, отрицательные значения).
- Прогресс не теряется: перезагрузка, импорт старой версии данных, два открытых таба.
- Стрик и календарь считаются по **локальной** дате.
- Нельзя фармить XP пересдачами одного теста (см. `04-features/gamification.md`).

## Архитектура
- Логика в `src/lib`, не в компонентах. Фичи не импортируют друг друга.
- Нет дублирования утилит.
- Типы из `src/types` — единственный источник правды.

## UX / UI
- 375px без горизонтального скролла.
- Обе темы, контраст.
- Состояния: загрузка, пусто, ошибка.
- Клавиатура, фокус, `prefers-reduced-motion`.

## Производительность
- Нет широких селекторов стора, вызывающих лишние ререндеры.
- Тяжёлые страницы lazy, свечи грузятся по требованию.

## Контент
- Нет обещаний прибыли, дисклеймеры на месте.
- Факты актуальны, дата сверки в брифе.

## Безопасность
- Импорт JSON валидируется zod-схемой.
- Нет `dangerouslySetInnerHTML` с пользовательскими данными.
