# Стандарты кода

## Общее
- TypeScript `strict: true`, `noUncheckedIndexedAccess: true`. Запрещены `any`, `@ts-ignore`, `as unknown as`.
- Функциональные компоненты + хуки. Без классов (кроме ErrorBoundary).
- Именованные экспорты. `default export` — только там, где требует инструмент (MDX-модули, lazy-страницы).
- Имена: компоненты `PascalCase.tsx`, хуки `useSomething.ts`, утилиты `camelCase.ts`, типы `PascalCase`.
- Файл ≤ ~250 строк. Больше — дробить.
- Импорты через алиас `@/` (→ `src/`).

## Слои
| Слой | Где | Правило |
|---|---|---|
| Чистая логика | `src/lib/**` | Без React, без DOM, без `Date.now()` внутри (время передаётся аргументом). Покрыто unit-тестами. |
| Состояние | `src/store/**` | Zustand-сторы. Действия вызывают функции из `lib`, сами логику не содержат. |
| Контент | `src/content/**` | MDX-уроки, `meta.ts`, `quiz.ts`. Без логики. |
| UI-кит | `src/components/ui/**` | Переиспользуемые примитивы без знаний о домене. |
| Схемы | `src/components/diagrams/**` | SVG-иллюстрации для уроков. |
| Фичи | `src/features/<feature>/**` | Компоненты и хуки одной фичи. Фичи не импортируют друг друга напрямую — только через `lib`/`store`/`components`. |
| Страницы | `src/pages/**` | Композиция фич. Минимум логики. |

## React
- Селекторы Zustand точечные: `useProgress(s => s.xp)`, не весь стор.
- Эффекты только для синхронизации с внешним миром (графики, storage). Производные значения — вычисление при рендере / `useMemo`.
- Списки — стабильные `key` (id), не индекс.
- Анимации — Framer Motion, уважать `prefers-reduced-motion`.
- Тяжёлые страницы (тренажёр, статистика, журнал) — `React.lazy`.

## Стили
- Tailwind v4, токены в `src/styles/tokens.css` (`@theme`). Хардкод цветов в компонентах запрещён — только токены.
- Условные классы через `cn()` (`clsx` + `tailwind-merge`).
- Mobile first: базовые классы для 375px, `md:`/`lg:` для больших экранов.

## Доступность
- Интерактив — только `<button>`/`<a>`/элементы форм, не `div onClick`.
- У иконок-кнопок `aria-label`. Контраст текста ≥ 4.5:1.
- Видимый фокус (`focus-visible`). Квиз проходится с клавиатуры.

## Числа и деньги
- Расчёты — `number`, округление только при выводе (`formatUsd`, `formatPct`, `formatPrice` из `src/lib/format.ts`).
- Проценты в логике — доли (0.01 = 1%), в UI — проценты.
