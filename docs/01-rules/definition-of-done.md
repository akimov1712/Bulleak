# Definition of Done

## Любая задача
- [ ] Выполнены все критерии приёмки из файла задачи.
- [ ] `npm run check` зелёный (typecheck + eslint + vitest).
- [ ] Новая логика покрыта unit-тестами, интерактивные компоненты — компонентными.
- [ ] UI проверен вживую (`preview_start`): ширина 1280 и 375, светлая и тёмная тема, нет ошибок в консоли.
- [ ] Нет хардкода цветов, `any`, `console.log`, закомментированного кода.
- [ ] Тексты интерфейса на русском, без опечаток.
- [ ] Чекбокс задачи отмечен, `docs/PROGRESS.md` обновлён.
- [ ] Коммит по правилам `git-workflow.md`.

## Контентная задача (урок) — дополнительно
- [ ] Выполнены все пункты брифа `docs/03-content/module-XX/lesson-YY.md`.
- [ ] Факты сверены, источники с датой записаны в бриф.
- [ ] Тест: 8–12 вопросов, ≥2 типа, у каждого объяснение.
- [ ] Картинки: лицензии в `credits.md`, alt-тексты.
- [ ] `content.test.ts` проходит.
- [ ] Урок пройден в браузере целиком, включая тест.

## Этап — дополнительно
- [ ] Все задачи этапа закрыты.
- [ ] `/code-review` по изменениям этапа, находки исправлены или обоснованно отклонены → `docs/06-qa/review-log.md`.
- [ ] `npm run e2e` зелёный.
- [ ] `npm run build` без ошибок; чанки > 500 кБ обоснованы.
- [ ] Результат показан пользователю, фидбэк записан в PROGRESS.md.
- [ ] Тег `stage-XX-done`.
