# Изображения

Сайт для личного обучения пользователя. Пользователь (2026-09-25) разрешил брать **любые подходящие фото** и отказался делать скриншоты Bybit сам.

## Что используем
1. **Свои SVG-схемы** (`src/components/diagrams/`): свечи, паттерны, уровни, структура рынка, ордера, стакан, ликвидация. Единый стиль, цвета из токенов. Основной вид иллюстраций.
2. **Живые графики** на реальных данных Bybit (`lightweight-charts`) с разметкой.
3. **Скриншоты интерфейса Bybit** (решение пользователя 2026-10-03: «вместо нарисованного UI — скриншоты, сделай их сам»). Снимает Claude скриптом `scripts/bybit-shots.ts` (Playwright, 2×, WebP) с публичного **testnet.bybit.com** — тот же веб-интерфейс, что у bybit.com, доступен без аккаунта (веб-терминал основного сайта открывается не из всех регионов). Показываются компонентом `BybitShot` с нумерованными зонами и пояснениями. Экраны, которые видны только в аккаунте, снимаются лишь после того, как пользователь сам войдёт в браузере (Claude не вводит учётные данные), а UID, e-mail, балансы и прочие личные данные скрываются до съёмки. Пока скриншота нет — остаётся SVG-макет. Список — [../03-content/bybit-mockups.md](../03-content/bybit-mockups.md).
4. **Фото и картинки** из любых источников в интернете (стоки, Wikimedia, статьи, Bybit Learn и т.п.) — по смыслу урока.

## Правила
- Изображения **скачиваются** в `public/img/<module>/`, никакого хотлинкинга (сайт должен работать офлайн).
- Перед скачиванием партии картинок — список файлов (имя, источник, размер) одним сообщением пользователю на подтверждение.
- Источник каждой картинки записывается в `docs/03-content/credits.md` (файл, URL, дата) — чтобы можно было найти/заменить.
- Приоритет качества: без водяных знаков, без чужих логотипов курсов, разрешение достаточное для ретины.
- Формат: WebP для фото (≤ 200 кБ, ширина ≤ 1600px), SVG для схем и макетов.
- У каждого изображения осмысленный `alt` на русском.
- Если сайт когда-нибудь станет публичным для других людей — пересмотреть картинки из источников без свободной лицензии (пометка `license: unknown` в credits помогает их найти).
