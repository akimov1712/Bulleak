# Изображения

## Приоритет
1. **Свои SVG-схемы** (`src/components/diagrams/`): свечи, паттерны, уровни, структура рынка, ордера, стакан, ликвидация. Единый стиль, цвета из токенов.
2. **Живые графики** на реальных данных Bybit (`lightweight-charts`) с разметкой.
3. **Фото** для обложек модулей — только **Unsplash / Pexels** (бесплатная лицензия) или **Wikimedia Commons** CC0/CC-BY/CC-BY-SA.
4. **Скриншоты Bybit**:
   - публичные страницы (главная, торговый терминал без входа, Help Center) — снимает Claude во встроенном браузере;
   - экраны внутри аккаунта — список в `docs/03-content/bybit-screenshots-todo.md`, снимает пользователь, кладёт в `public/img/bybit/`.

## Правила
- Каждое внешнее изображение → строка в `docs/03-content/credits.md`: файл, автор, URL, лицензия, дата.
- Запрещено: картинки без понятной лицензии, материалы чужих курсов, платные стоки, водяные знаки.
- Формат: WebP для фото (≤ 200 кБ, ширина ≤ 1600px), SVG для схем, PNG для скриншотов.
- Путь: `public/img/<module>/<name>.webp`.
- У каждого изображения осмысленный `alt` на русском.
