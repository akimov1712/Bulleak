# Правила контента

## Тон
- На «ты», дружелюбно, коротко. Новый термин — **жирным** при первом упоминании и ссылкой в глоссарий (`<Term id="...">`).
- Честно про риски. Запрещены обещания («гарантированный доход», «легко заработать», «стратегия 100%»).
- Примеры с реалистичными суммами для новичка ($100–$1000).

## Структура урока (MDX)
1. **Заголовок + «Что узнаешь»** — 3–5 пунктов (`<Goals>`).
2. **Теория** — блоки по 2–4 абзаца, между ними визуал. Абзац ≤ 4 предложений.
3. **Интерактив** — минимум один: `<CandleChart>`, калькулятор, `<MiniQuiz>`, `<SimScenario>`, `<Reveal>`.
4. **Callout-блоки**: `<Tip>`, `<Warning>`, `<Example>`, `<BybitNote>` (как это выглядит на бирже).
5. **Итоги** — 3–6 пунктов (`<Summary>`).
6. **Тест** — `quiz.ts`, 8–12 вопросов.

Объём: 600–1800 слов, 5–15 минут чтения. Пилот (модули 0–3, 650–750 слов) пользователь принял без замечаний — компактность важнее объёма, длиннее пишем только там, где тема требует (фьючерсы, риск, стратегия).

## Тесты
- 8–12 вопросов, ≥2 типа. Уроки с расчётами — обязательно `numeric`; уроки про графики — `chart-click` или вопрос с изображением графика.
- У каждого вопроса `explanation`: почему правильный ответ верен и почему типичная ошибка неверна.
- Неправильные варианты правдоподобные.
- Проверяем понимание и применение, не зубрёжку.
- Порядок вариантов перемешивается — не писать «все вышеперечисленные».

## Факты и источники
- Всё про Bybit (комиссии, ордера, маржа, funding, ликвидация, интерфейс) — сверять с Bybit Help Center / Bybit Learn / Bybit API docs, в брифе URL и дата сверки.
- Общая теория — Investopedia, Babypips, CoinGecko/CoinMarketCap Learn, TradingView docs. Пересказ своими словами.
- Изменчивые значения — «на момент написания (месяц год)» + ссылка.

## Бриф урока
Шаблон: id, заголовок, цели, ключевые тезисы, визуалы, интерактив, идеи вопросов, термины глоссария, источники, связи.
