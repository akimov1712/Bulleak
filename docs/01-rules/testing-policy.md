# Политика тестирования

## Уровни
| Уровень | Инструмент | Что покрываем | Где |
|---|---|---|---|
| Unit | Vitest | Вся логика `src/lib/**`: XP, уровни, стрики, достижения, оценка квиза, риск, ликвидация, симуляция сделки, метрики журнала, миграции стора, валидация импорта | `src/lib/**/*.test.ts` |
| Компонентные | Vitest + Testing Library + jsdom | Вопросы квиза, калькуляторы, форма журнала, карта пути (блокировки) | рядом с компонентом `*.test.tsx` |
| Контент | Vitest | Все уроки: есть meta, тест 8–12 вопросов, у каждого вопроса explanation, правильный ответ существует, id уникальны, ссылки на глоссарий валидны | `src/content/content.test.ts` |
| E2E | Playwright (Chromium, desktop + mobile 375px) | Критические сценарии из `docs/06-qa/test-plan.md` | `e2e/*.spec.ts` |

## Правила
- Тесты пишутся **в той же задаче**, что и код.
- Для логики — крайние случаи: 0, отрицательные, пустые массивы, граница 80% в квизе, смена суток для стрика.
- Время фиксируется (`vi.setSystemTime`) или передаётся параметром.
- E2E не зависят от сети: свечи — из `public/data`.
- Порог покрытия `src/lib/**`: 90% строк.
- Упавший тест не отключается без записи в `docs/06-qa/bug-log.md`.
