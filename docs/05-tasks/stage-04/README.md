# Этап 04 · Графики и пилотный контент (модули 0–3)

## Цель
Реальные данные Bybit, свечной график с разметкой и индикаторами, вопрос chart-click. Первые 19 уроков и 3 экзамена полностью готовы. После этапа пользователь начинает учиться и даёт фидбэк по стилю.

## Результат этапа (демонстрация пользователю)
- Модули 0–3 проходятся целиком
- Живые графики BTC/ETH/SOL с разметкой в уроках
- Экзамены M1–M3
