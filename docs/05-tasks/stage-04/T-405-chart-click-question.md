## Заметки по реализации
- Разметка обновляется на существующем графике (без пересоздания): клик не сбрасывает зум и не мигает.
- lightweight-charts склеивает два клика в разных точках быстрее ~0,5 с в «двойной клик» и не сообщает о втором — ответ переставляется со следующего клика. Двойной клик в одной точке обрабатывается как клик.
- Доступность: для цены — поле ввода числом; для свечи — кнопки «◀ ▶» с озвучкой «Свеча N из M».
- Индексы в вопросах ссылаются на замороженные датасеты (см. market-data.md «Заморозка датасетов»).
