# T-1201 · Тёмный сайдбар с профилем, без шапки на десктопе

- **Этап:** 12 Навигация, вторая версия
- **Статус:** ✅ готово

## Что сделать
1. Сайдбар — тёмная «чернильная» панель в обеих темах (токены `ink*`), фирменный зелёный акцент активного раздела, монохромные иконки вместо цветных плиток.
2. Убрать карточку «Продолжить» из сайдбара (большая карточка остаётся на главной).
3. Шапку на десктопе убрать: имя, уровень с прогрессом, серия, опыт с кольцом цели дня и переключатель темы — в карточке профиля наверху сайдбара.
4. Мобильная шапка — в той же тёмной палитре: знак, компактный прогресс, тема.

## Критерии приёмки
- [x] Сайдбар помещается в экран 900 px без прокрутки; шапка телефона — от 320 px без переполнения; кнопки ≥ 44 px
- [x] Всплывающие подсказки серии, цели дня и уровня работают как раньше
- [x] Выполнен [Definition of Done](../../01-rules/definition-of-done.md)
