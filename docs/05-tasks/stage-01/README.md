# Этап 01 · Каркас приложения и дизайн-система

## Цель
Навигация, все страницы-заглушки, UI-кит в игровом стиле, маскот, темы. Сайт уже выглядит как продукт, хотя контента ещё нет.

## Результат этапа (демонстрация пользователю)
- Переходы по всем разделам на десктопе и мобильном
- Витрина UI-кита `/#/dev/ui` в светлой и тёмной теме
- Маскот во всех настроениях
