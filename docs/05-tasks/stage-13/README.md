# Этап 13 · Сервер и авторизация

## Цель
Свой API (Node 24 + Hono + PostgreSQL/Drizzle) с регистрацией, входом, сессиями, подтверждением e-mail и сбросом пароля. Всё локально и в тестах (PGlite), без внешних сервисов. ТЗ — [accounts-backend.md](../../04-features/accounts-backend.md).

## Результат этапа (демонстрация пользователю)
- Сервер запускается локально, API авторизации покрыт тестами
- CI проверяет фронтенд и сервер
