# Этап 11 · Бренд и оформление

## Цель
У сайта есть свой бренд **Bulleak**: логотип (без маскота), название в навигации, единый стиль иконок приложения. Верхняя панель прогресса и боковая навигация выглядят профессионально и живо.

Основание — отзыв пользователя 2026-09-30: верхняя панель «слишком простая и непрофессиональная», левая панель «скучная», у сайта нет бренда; маскот Буллик остаётся персонажем, но не логотипом.

## Результат этапа (демонстрация пользователю)
- Логотип Bulleak в сайдбаре, на мобильной шапке, во вкладке браузера и в иконке приложения
- Новая боковая панель: группы разделов, цветные иконки, карточка «Продолжить»
- Новая верхняя панель: серия, цель дня, уровень с прогрессом
