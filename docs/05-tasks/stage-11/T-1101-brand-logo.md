## Что сделать
1. Знак: собственный SVG — голова быка из свечи (тело свечи — голова, фитиль, два рога), на плитке с фирменным зелёным градиентом. Без маскота.
2. Словесный знак «Bulleak» + подпись «Трейдинг на Bybit с нуля»; компонент `Logo` (полный и компактный вариант).
3. Favicon, иконки PWA (192/512/maskable/apple-touch) из нового знака.
4. Название в заголовках вкладок, манифесте PWA, статической оболочке index.html.
5. Токены бренда в `tokens.css`, раздел «Бренд» в design-system.md.

## Критерии приёмки
- [x] Знак читается в 16–32 px (вкладка браузера) и в 512 px (иконка приложения)
- [x] Обе темы, контраст подписи ≥ 4.5:1
- [x] Выполнен [Definition of Done](../../01-rules/definition-of-done.md)
