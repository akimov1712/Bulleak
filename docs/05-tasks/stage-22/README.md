# Этап 22 · Подсказки

## Цель
Подсказки ведут к ответу, а не выдают его: лестница в тестах, разметка и проверка правил в тренажёре, советы по своим сделкам, тур для новичка. ТЗ — [hints.md](../../04-features/hints.md).

## Результат этапа (демонстрация пользователю)
- Лестница подсказок в тесте урока
- Проверка ордера перед входом и разметка в тренажёре
- Тур для нового ученика
