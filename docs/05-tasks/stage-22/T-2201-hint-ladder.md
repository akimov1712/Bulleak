**Примечание:** Намёк убирает неверные варианты, оставляя один (в своём порядке вопроса, не перемешанном). Правило — короткое определение термина первого тега и название урока (без ссылки, чтобы не терять тест). Разбор — пояснение без верного варианта. Ступень 2+ снимает бонусы «без ошибок» / «почти идеально» и счётчик идеальных тестов; в BKT ответ после правила — с угадыванием 0,5, после разбора — как неверный.
