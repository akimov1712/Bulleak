# T-2203 · Проверка перед входом

- **Этап:** 22 Подсказки

## Контекст (прочитать перед началом)
- [ТЗ: подсказки](../../04-features/hints.md), раздел 3
- [Модель ученика](../../04-features/learner-model.md)

## Что сделать
1. Проверка черновика правилами дисциплины, список нарушений с «Исправить» и «Всё равно открыть».
2. Чек-лист перед сделкой над кнопкой.

## Критерии приёмки
- [x] Тесты проверки черновика; тест панели ордера
- [x] Выполнен [Definition of Done](../../01-rules/definition-of-done.md)

**Примечание:** Черновик проверяется как следующая сделка после своих сделок тренажёра (риск, R:R, дневной лимит, месть); при нарушениях — окно со списком, «Исправить» и «Всё равно открыть». В бэктесте стратегии проверка не нужна. Чек-лист перед сделкой — раскрывающийся блок над кнопкой. Проверено вживую.

**Коммит:** `feat(simulator): check the order against the rules before entry`
