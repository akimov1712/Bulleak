# Этап 05 · Тренажёр

## Цель
Торговля «вслепую» на истории Bybit: свободный режим, сценарии уроков, режим бэктеста, виртуальный баланс, история сделок.

## Результат этапа (демонстрация пользователю)
- Свободный режим: вход, SL/TP перетаскиванием, воспроизведение, результат в R
- Сценарий из урока с разбором
- Режим бэктеста с чек-листом стратегии
