## Контекст (прочитать перед началом)

## Что сделать
1. Попросить пользователя установить GitHub CLI (winget install GitHub.cli) и выполнить `gh auth login` самостоятельно (Claude не вводит учётные данные)
2. Согласовать имя репозитория и видимость: для бесплатного GitHub Pages нужен публичный репозиторий
3. Проверить, что в репозитории нет личных данных

## Критерии приёмки
- [ ] `gh auth status` показывает вход
- [ ] Пользователь явно подтвердил создание репозитория
- [ ] Выполнен [Definition of Done](../../01-rules/definition-of-done.md)
