## Что сделать
1. Попытка теста хранит ответы по вопросам: id, верно, теги, время, уверенность. Миграция прогресса не нужна: поле необязательное.
2. Функция `learningEvents(progress, trades)`: ответы и сделки по времени; старые попытки — по сводке тегов.

## Критерии приёмки
- [x] Тесты: новые и старые попытки, бэктесты не входят, слияние прогресса сохраняет ответы
- [x] Выполнен [Definition of Done](../../01-rules/definition-of-done.md)

**Примечание:** Ответы хранятся в `QuizAttempt.answers` (поле необязательное, версия прогресса не меняется); уверенность добавится в T-1910. Время на вопрос — от показа до проверки. Старые попытки восстанавливаются из сводки тегов.

**Коммит:** `feat(learner): record answers and derive learning events`
