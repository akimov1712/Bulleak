## Что сделать
1. Проверка в `content.test.ts`: каждый вопрос тестов уроков, экзаменов и финала относится хотя бы к одному навыку.
2. Уроки навыка существуют, и их тесты проверяют теги навыка. Недостающие теги добавить в граф.

## Критерии приёмки
- [x] Проверка зелёная на всём курсе
- [x] Выполнен [Definition of Done](../../01-rules/definition-of-done.md)

**Примечание:** Разметка — через теги: вопрос относится к навыкам, с которыми делит тег, отдельного поля не нужно. Проверка: каждый вопрос уроков, экзаменов и финала имеет навык, у каждого навыка ≥ 5 вопросов, тест каждого урока навыка проверяет его теги.

**Коммит:** `test(content): check every question maps to a skill`
