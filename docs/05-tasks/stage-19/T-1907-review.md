## Что сделать
1. Расписание повторений по навыкам и выбор до 3 навыков на сегодня.
2. Блок «Сегодня повторить» на главной и короткий тест из вопросов уроков навыка.

## Критерии приёмки
- [x] Тесты расписания; e2e: блок появляется после теста и пропадает после повторения
- [x] Выполнен [Definition of Done](../../01-rules/definition-of-done.md)

**Примечание:** Повторение — событие `reviewCompleted` (попытка с quizId `review`, +15 XP при ≥ 60 %). «Сегодня» = срок наступает до конца дня. Вопросы: сначала ошибки прошлого раза, затем невиденные, затем давно отвеченные, по кругу между навыками. Вместо e2e — тест страницы через настоящий роутер (сценарий требует сдвига времени на дни); вживую проверено в превью.

**Коммит:** `feat(learner): add spaced review`
