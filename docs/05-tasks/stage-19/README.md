# Этап 19 · Модель ученика

## Цель
Сайт понимает, какие навыки ученик знает, какие применяет в тренажёре и где знание расходится с делом. На этом строятся повторения, следующий шаг, подсказки (этап 22) и ИИ-разборы (этап 24). ТЗ — [learner-model.md](../../04-features/learner-model.md).

## Результат этапа (демонстрация пользователю)
- Страница «Мои навыки»: что знаю, что применяю, где разрыв
- «Сегодня повторить» на главной
- Следующий шаг выбирается по модели
