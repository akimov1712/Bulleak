# T-1702 · Скриншоты экранов аккаунта

- **Этап:** 17 Скриншоты Bybit
- **Статус:** ☐ ждёт входа пользователя

## Что сделать
Экраны видны только в аккаунте: безопасность и верификация (m02-l01), активы и депозит (m02-l02), форма ордера с TP/SL (m02-l05), демо-торговля (m02-l06), плечо и режим маржи (m08-l03), открытая позиция (m08-l04, m11-l03), алерт (m10-l02), выгрузка истории (m12-l03).
1. Claude открывает окно браузера со своим профилем; пользователь сам входит в аккаунт (лучше — отдельный аккаунт тестовой сети, без реальных денег). Claude учётные данные не вводит.
2. Перед каждым снимком скрываются UID, e-mail, телефон, балансы, адреса кошельков.
3. Снимки показываются пользователю до публикации.
