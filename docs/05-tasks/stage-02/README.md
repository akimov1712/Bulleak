# Этап 02 · Движок уроков и тестов

## Цель
Урок в MDX открывается, читается, засчитывается; тест проходится со всеми типами вопросов (кроме chart-click, он на этапе 04); прогресс сохраняется и переживает перезагрузку.

## Результат этапа (демонстрация пользователю)
- Урок-образец m00-l01 (черновой текст) со всеми MDX-компонентами
- Тест-образец со всеми типами вопросов
- Перезагрузка страницы сохраняет прогресс
