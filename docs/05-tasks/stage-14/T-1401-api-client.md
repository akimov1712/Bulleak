## Что сделать
1. Клиент `src/api`: запросы к API, проверка ответов схемами `@bulleak/shared`, ошибки с кодом и полями.
2. Access-токен только в памяти; refresh-токен и пользователь — в localStorage (режим `body`) или в cookie (режим `cookie`).
3. Автоматическое обновление токена при 401, одно на все вкладки (Web Locks), повтор запроса.
4. Стор `useAuth`: статус и пользователь, синхронизация между вкладками.
5. Без `VITE_API_URL` клиент не создаётся, сайт работает как раньше.
