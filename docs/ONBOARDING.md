# Продолжить проект на другом компьютере

Инструкция для человека (и его Claude Code), который подхватывает работу на новом ПК. Всё нужное для работы лежит в репозитории: код, ТЗ (`docs/`), исторические свечи (`public/data/`), конфигурация превью (`.claude/launch.json`). Ничего скачивать с биржи не нужно.

## 1. Установить
- **Git** 2.39+ и доступ к репозиторию `https://github.com/akimov1712/Bulleak` (вход в GitHub делает сам человек — `gh auth login` или Git Credential Manager; ключи и токены в репозиторий не кладём).
- **Node.js 24 LTS** (минимум 22 — см. `engines` в `package.json`).
- **Claude Code** (десктоп-приложение, CLI или расширение IDE).

## 2. Склонировать и поставить зависимости
```bash
git clone https://github.com/akimov1712/Bulleak.git TradingLearning
```
```bash
cd TradingLearning
```
```bash
npm ci
```
```bash
npx playwright install chromium
```

## 3. Проверить, что всё работает
```bash
npm run check
```
Должно быть зелёным (typecheck, lint, формат, ~700 unit-тестов). Затем `npm run e2e` (Playwright поднимает сервер сам).

## 4. Запустить сайт
- В Claude Code (десктоп): `preview_start` с конфигурацией `web` из `.claude/launch.json` — Vite на порту 5173, слушает всю локальную сеть (`http://<IP-компьютера>:5173/`), HMR выключен (режим `pane`) — после правок перезагружать страницу.
- Вручную: `npm run dev` → http://localhost:5173/

## 5. Как продолжить работу (для Claude)
1. Прочитать `CLAUDE.md` (правила) → `docs/README.md` (карта ТЗ) → `docs/PROGRESS.md` (где остановились, решения и отзывы пользователя).
2. Взять следующую задачу из `docs/05-tasks/stage-XX/`, выполнить по Definition of Done.
3. Коммит только после зелёного `npm run check` (цепочкой `&&`, не `;`), **сразу `git push origin main`**.
4. В конце этапа: `/code-review`, исправления, e2e, запись в `docs/06-qa/review-log.md`, тег `stage-XX-done` (тоже пушится), демонстрация пользователю и ожидание отзыва.

## Контекст, который не виден из кода
- Пользователь — новичок в трейдинге, общается по-русски; сайт личный, прогресс хранится только в браузере.
- Работа строго по этапам с демонстрацией после каждого; отзывы пользователя записываются в `docs/PROGRESS.md`.
- Скриншотов Bybit нет и не будет — вместо них собственные SVG/HTML-макеты интерфейса. Фото можно брать любые (сайт личный), но список партии показывать пользователю до скачивания.
- Наборы свечей в `public/data/` **заморожены** тестом: вопросы, сценарии тренажёра и тексты уроков ссылаются на свечи по индексу. `npm run data:fetch` без необходимости не запускать.
- Исходный ПК — 8 ГБ ОЗУ: поэтому Vitest `maxWorkers: 2` и Playwright 2 воркера локально. Падения с кодом 134 / 3221226505 / «out of memory» — нехватка памяти, а не баг; на более мощной машине лимиты можно не трогать.
- Windows: команды, поднимающие локальный сервер (`npm run e2e`), запускать через PowerShell, не через Bash-песочницу Claude Code.
