# m03-l03 · Тренд и структура рынка

- **Модуль:** 3   **Время:** ~14 мин   **Практика:** CandleChart с HH/HL, chart-click
- **Статус:** ☑ бриф ☑ текст ☑ визуалы ☑ тест ☑ проверен в браузере

## Цели
1. Определять тренд по структуре: HH/HL — восходящий, LH/LL — нисходящий, иначе — флэт.
2. Находить свинг-хаи и свинг-лоу.
3. Понимать слом структуры (BOS / смена характера) как сигнал возможной смены тренда.

## Ключевые тезисы
- Swing high — вершина, у которой по 2+ свечи с каждой стороны ниже (правило фрактала — для объективности).
- Восходящий тренд: каждый максимум и минимум выше предыдущих.
- Слом структуры: в аптренде цена закрылась ниже последнего HL → тренд под вопросом.
- Рынок большую часть времени во флэте — торговать тренд проще новичку.
- «Тренд — друг»: свинг-стратегия курса торгует по тренду старшего ТФ.

## Визуалы
- Diagram `market-structure` — зигзаг с подписями HH/HL/LH/LL и BOS.
- CandleChart `BTCUSDT-D` с автоматической разметкой свингов (функция `findSwings` в lib, тоже пригодится в тренажёре).

## Интерактив
- «Разметь сам»: кликнуть 4 свинг-точки → сравнение с авторазметкой.
- Сценарий тренажёра `m03-trend-pullback` (вход по тренду на откате) — опционально.

## Идеи вопросов теста
- [single] Признак восходящего тренда.
- [chart-click] Кликни на последний Higher Low (candle).
- [truefalse] Флэт — это когда максимумы и минимумы примерно на одном уровне — верно.
- [single] Что такое слом структуры.
- [order] Последовательность точек аптренда: HL → HH → HL → HH (упрощённо).
- [single] В каком направлении искать сделки в аптренде.
- [chart-click] Где произошёл слом структуры (candle).
- [multi] Состояния рынка.
- [single] Правило фрактала для swing high.
