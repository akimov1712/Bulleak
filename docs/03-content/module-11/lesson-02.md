# m11-l02 · Собираем свинг-стратегию: тренд + зона + триггер

- **Модуль:** 11   **Время:** ~16 мин   **Практика:** сценарии
- **Статус:** ☑ бриф ☐ текст ☐ визуалы ☐ тест ☐ проверен в браузере

## Цели
1. Освоить базовую стратегию курса **Trend Pullback Swing (TPS)**.
2. Пройти сетап по шагам на 3 исторических примерах.
3. Заполнить свою версию стратегии в редакторе (параметры можно менять).

## Правила TPS (лонг; шорт — зеркально)
1. **Контекст 1D:** цена выше EMA 200 и структура HH/HL (последний слом структуры — вверх).
2. **Зона 4H:** цена откатывается в зону интереса — хотя бы 2 из 3 (конфлюенс): флип-уровень поддержки, EMA 50 (4H), Фибо 0.5–0.618 последнего импульса.
3. **Триггер 1H:** в зоне — бычье поглощение / пин-бар **или** слом нисходящей 1H-структуры (закрытие выше последнего LH).
4. **Стоп:** за минимумом отката (свинг-лоу 1H/4H) + 0.5 ATR(14, 4H).
5. **Цель:** ближайшее сопротивление 4H, **но не менее 2R**; если до сопротивления < 2R — сделку не брать.
6. **Отмена:** закрытие 4H под зоной до триггера; важная новость в ближайшие 12 ч; суммарный открытый риск > 3%.
7. **Риск:** 1% (0.5% в просадке, m09-l04), плечо ≤ 3x, изолированная маржа.
