# m11-l01 · Из чего состоит стратегия

- **Модуль:** 11 Своя свинг-стратегия   **Время:** ~11 мин   **Практика:** Diagram
- **Статус:** ☑ бриф ☐ текст ☐ визуалы ☐ тест ☐ проверен в браузере

## Цели
1. Знать обязательные компоненты стратегии: рынок, контекст/фильтр, зона, триггер входа, стоп, цель, управление позицией, условия отмены.
2. Понимать требование **однозначности**: два человека по правилам должны принять одно решение.
3. Отличать «стиль» от «стратегии».

## Ключевые тезисы
- Стратегия = набор проверяемых правил «если… то…».
- Проверка однозначности: можно ли записать правило как чек-лист с да/нет.
- Меньше правил → устойчивее к подгонке.
- Стратегия курса — **Trend Pullback Swing** (подробно в m11-l02) — стартовая точка, которую ученик адаптирует.

## Визуалы
- Diagram `strategy-anatomy` — блок-схема компонентов.

## Идеи вопросов теста
- [multi] Обязательные компоненты стратегии.
- [single] Что такое триггер.
- [single] Признак неоднозначного правила («цена выглядит сильной»).
- [truefalse] Хорошая стратегия может опираться на интуицию без правил — неверно.
- [order] Порядок компонентов при принятии решения.
- [single] Почему меньше правил лучше.
- [single] Что такое условие отмены сетапа.
- [single] Разница стиля и стратегии.
