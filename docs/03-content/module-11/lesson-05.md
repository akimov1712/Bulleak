# m11-l05 · Метрики стратегии и ловушка подгонки

- **Модуль:** 11   **Время:** ~13 мин   **Практика:** статистика
- **Статус:** ☑ бриф ☑ текст ☑ визуалы ☑ тест ☑ проверен в браузере

## Цели
1. Оценивать бэктест по метрикам: число сделок, винрейт, средний R, матожидание, profit factor, макс. просадка, макс. серия убытков.
2. Учитывать издержки (комиссии, funding, проскальзывание) — «чистое» матожидание.
3. Понимать переоптимизацию и правила изменения стратегии.

## Ключевые тезисы
- Порог курса для перехода к форвард-тесту: ≥ 30 сделок, E ≥ +0.2R после издержек, PF ≥ 1.3, макс. просадка ≤ 15% при риске 1%.
- Если не проходит: менять **одно** правило за раз и тестировать на **новых** данных.
- Подгонка: чем больше параметров подобрано под историю, тем хуже в будущем.
- In-sample / out-of-sample: часть истории оставить для проверки.

## Визуалы
- Экран «Отчёт бэктеста» из статистики тренажёра (фильтр по strategyTag).
- Diagram `overfitting` — идеальная кривая на истории vs реальность.

## Идеи вопросов теста
- [numeric] 12 выигрышей по 2R, 18 проигрышей по 1R → E (0.2).
- [numeric] PF для того же (1.33, tolerance 0.02).
- [single] Что такое переоптимизация.
- [single] Сколько правил менять за раз.
- [truefalse] Бэктест с E +0.5R гарантирует прибыль в реале — неверно.
- [single] Out-of-sample — это.
- [multi] Издержки, которые нужно учесть.
- [single] Порог курса для перехода к форвард-тесту.

## Термины
`profit-factor`, `expectancy`, `overfitting`, `out-of-sample`

Сверено 2026-09-29:
