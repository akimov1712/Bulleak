## Цели
1. Иметь план развития на 6–12 месяцев после курса.
2. Знать направления углубления: объёмный анализ/профиль, ордерфлоу, алгоритмическая торговля и API Bybit, опционы — только после стабильности базовой стратегии.
3. Подготовиться к финальному экзамену.

## Ключевые тезисы
- Ежемесячный цикл: разбор журнала → одно улучшение → тест → внедрение.
- Критическое мышление к «гуру», сигналам и курсам с обещаниями.
- Сообщество и обмен разборами — полезно, копирование сделок — нет.
- Что повторить перед финальным экзаменом (ссылки на слабые темы из статистики).

- Блок «Твои слабые темы» (данные из stats).
