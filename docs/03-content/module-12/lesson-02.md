# m12-l02 · Первый депозит и правила масштабирования

- **Модуль:** 12   **Время:** ~11 мин   **Практика:** CalcEmbed compounding
- **Статус:** ☑ бриф ☐ текст ☐ визуалы ☐ тест ☐ проверен в браузере

## Цели
1. Выбрать размер первого реального депозита (минимальный, который не жалко; пример $100–$500).
2. Понимать психологический скачок «демо → реал» и начать с уменьшенного риска (0.5%).
3. Знать правила масштабирования: увеличивать риск/депозит только по данным.

## Ключевые тезисы
- Первые 30 реальных сделок — проверка исполнения с настоящими эмоциями.
- Масштабирование ступенями: после каждых 30 сделок с E > 0 и соблюдением плана — риск 0.5% → 0.75% → 1%, депозит — только из собственных сбережений по плану, не «доливать после убытка».
- Откат на ступень назад при нарушении лимитов или просадке > 10%.
- Вывод части прибыли — полезная привычка.
- Маленький депозит + комиссии: следить за минимальными объёмами Bybit.

## Идеи вопросов теста
- [single] Риск на первых реальных сделках.
- [single] Когда повышать ступень.
- [truefalse] После убытка стоит довнести депозит, чтобы отыграться — неверно.
- [single] Когда откатываться на ступень назад.
- [numeric] Депозит $300, риск 0.5% → $1.5.
- [single] Почему реал отличается от демо.
- [multi] Правила масштабирования.
- [single] Зачем выводить часть прибыли.
