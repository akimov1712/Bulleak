# m06-l03 · Ликвидность и охота за стопами

- **Модуль:** 6   **Время:** ~13 мин   **Практика:** CandleChart, сценарий
- **Статус:** ☑ бриф ☐ текст ☐ визуалы ☐ тест ☐ проверен в браузере

## Цели
1. Понимать, где скапливаются стоп-ордера (за очевидными экстремумами, равными максимумами/минимумами, круглыми числами).
2. Узнавать «снятие ликвидности» (sweep): прокол экстремума тенью и возврат.
3. Не ставить стоп «туда же, где все», и использовать sweep как подтверждение.

## Ключевые тезисы
- Стоп лонгистов = рыночные продажи; крупному участнику нужна ликвидность для набора позиции.
- Равные минимумы — «магнит».
- Sweep + возврат под/над уровень + закрытие = признак ложного движения.
- Каскады ликвидаций на фьючерсах усиливают такие проколы (связь с M8).
- Не превращать в конспирологию: это вероятностная идея, не «маркетмейкер охотится лично за тобой».
