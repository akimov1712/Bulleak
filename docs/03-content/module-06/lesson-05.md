# m06-l05 · Дивергенции

- **Модуль:** 6   **Время:** ~11 мин   **Практика:** CandleChart + RSI
- **Статус:** ☑ бриф ☑ текст ☑ визуалы ☑ тест ☑ проверен в браузере

## Цели
1. Находить регулярную бычью/медвежью дивергенцию цены и RSI/MACD.
2. Понимать скрытую дивергенцию как сигнал продолжения.
3. Понимать, что дивергенция — предупреждение, а не сигнал входа.

## Ключевые тезисы
- Медвежья регулярная: цена HH, RSI LH → импульс слабеет.
- Бычья регулярная: цена LL, RSI HL.
- Скрытая бычья: цена HL, RSI LL — продолжение аптренда.
- Дивергенции могут «накапливаться» долго; нужен триггер (слом структуры).

## Визуалы
- Diagram `divergence-types` (4 вида).
- CandleChart + RSI с отмеченной дивергенцией на реальных данных.

## Идеи вопросов теста
- [single] Определение медвежьей регулярной дивергенции.
- [match] Тип дивергенции ↔ картина цены/индикатора.
- [truefalse] Дивергенция — самостоятельный сигнал на вход — неверно.
- [chart-click] Где второй максимум медвежьей дивергенции.
- [single] Что такое скрытая дивергенция.
- [single] Что нужно для входа после дивергенции.
- [single] С какими индикаторами ищут дивергенции.
- [multi] Ошибки при торговле дивергенций.
