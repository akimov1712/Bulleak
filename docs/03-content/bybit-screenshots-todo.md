# Скриншоты Bybit — задание для пользователя

Claude не заходит в аккаунт. Эти экраны снимает пользователь (лучше с **демо-счёта**, чтобы не светить реальные балансы) и кладёт в `public/img/bybit/` под указанным именем.
Перед съёмкой: скрыть email/UID/балансы (или замазать), язык интерфейса — русский (если доступен) или английский, тёмная тема.
