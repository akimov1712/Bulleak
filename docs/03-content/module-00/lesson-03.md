# m00-l03 · Как устроен курс: путь бумага → тренажёр → тестнет → реал

- **Модуль:** 0 Старт   **Время:** ~7 мин   **Практика:** Checklist
- **Статус:** ☑ бриф ☐ текст ☐ визуалы ☐ тест ☐ проверен в браузере

## Цели
1. Знать структуру курса: 13 модулей, тесты, экзамены, финал.
2. Понимать инструменты сайта: карта, тренажёр, калькуляторы, журнал, глоссарий, статистика.
3. Знать правила продвижения: 80% для сдачи, экзамены открывают модули.
4. Настроить цель дня и режим занятий.

## Ключевые тезисы
- Путь из 4 ступеней риска: теория и тесты → тренажёр на истории → демо/тестнет Bybit с журналом → реальный счёт с минимальной суммой.
- Правила «перехода на ступень»: например, на реальный счёт — только после ≥30 сделок форвард-теста с положительным матожиданием и соблюдением плана ≥ 90%.
- Как работают XP, уровни, стрик, достижения; совет: 1 урок в день, 20–40 минут.
- Резервная копия прогресса (данные хранятся в браузере) — где кнопка.
- Как читать уроки: термины с подсказками, блоки «Совет/Риск/Пример/Bybit».

## Визуалы
- Diagram `course-roadmap` — лестница из 4 ступеней + модули.
- Скриншоты своего сайта не нужны — живые ссылки на разделы.

## Интерактив
- Checklist «Мои обязательства»: учусь каждый день, не торгую реальными деньгами до модуля 12, веду журнал, риск ≤ 1%.
- Кнопка «Настроить цель дня» → /settings.

## Идеи вопросов теста
- [single] Какой порог для сдачи теста (80%).
- [order] Ступени пути.
- [single] Где хранится прогресс и как не потерять (экспорт).
- [single] Что открывает следующий модуль (экзамен).
- [truefalse] Можно начать реальную торговлю после модуля 3 — неверно по плану курса.
- [single] Для чего тренажёр.
- [multi] Какие инструменты есть на сайте.
- [single] Рекомендуемый темп.
