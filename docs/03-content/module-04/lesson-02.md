# m04-l02 · Свечные комбинации

- **Модуль:** 4   **Время:** ~12 мин   **Практика:** Diagram, chart-click
- **Статус:** ☑ бриф ☑ текст ☑ визуалы ☑ тест ☑ проверен в браузере

## Цели
1. Узнавать поглощение, харами (inside bar), утреннюю/вечернюю звезду, твизер.
2. Понимать логику каждого паттерна через борьбу покупателей и продавцов.
3. Использовать inside bar как паттерн сжатия.

## Ключевые тезисы
- Бычье поглощение: тело зелёной свечи перекрывает тело предыдущей красной.
- Inside bar: вся свеча внутри диапазона предыдущей — сжатие, пробой диапазона как триггер.
- Утренняя звезда: большая красная → маленькая → большая зелёная, закрытие выше середины первой.
- Твизер: два одинаковых экстремума подряд.
- Статистика паттернов сама по себе слабая — используем только как триггер входа от зоны.

## Визуалы
- Diagram `two-three-candle-patterns`.
- CandleChart с отмеченными поглощениями (`detectEngulfing`).

## Идеи вопросов теста
- [single] Определение бычьего поглощения.
- [chart-click] Найди inside bar.
- [order] Последовательность свечей утренней звезды.
- [truefalse] Поглощение в середине флэта — сильный сигнал — неверно.
- [single] Как торговать пробой inside bar.
- [match] Паттерн ↔ тип (разворот/сжатие).
- [single] Что такое твизер.
- [single] Роль паттерна в стратегии курса (триггер).
