# m02-l02 · Счета Bybit, пополнение и переводы

- **Модуль:** 2   **Время:** ~10 мин   **Практика:** Steps
- **Статус:** ☑ бриф ☐ текст ☐ визуалы ☐ тест ☐ проверен в браузере

## Цели
1. Понимать структуру счетов Bybit (Funding, Unified Trading Account) — сверить актуальные названия.
2. Знать способы пополнения (крипто-депозит, P2P, карта) и их риски.
3. Делать внутренние переводы между счетами и понимать сети при переводе крипты.

## Ключевые тезисы
- Funding-счёт — для депозитов/выводов/P2P; торговый счёт (UTA) — для спота и деривативов.
- Депозит крипты: выбор сети (TRC20, ERC20, и т.д.), совпадение сети отправителя и получателя, memo/tag. Ошибка сети = потеря средств.
- Тестовый перевод маленькой суммы.
- P2P: риски (мошенники, «грязные» деньги), правила безопасных сделок — только внутри платформы.
- Внутренний перевод между счетами бесплатный и мгновенный (сверить).
- В курсе реальные деньги понадобятся только в модуле 12.
