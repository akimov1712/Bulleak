# m09-l05 · Лимиты риска и корреляция

- **Модуль:** 9   **Время:** ~10 мин   **Практика:** Checklist
- **Статус:** ☑ бриф ☐ текст ☐ визуалы ☐ тест ☐ проверен в браузере

## Цели
1. Установить лимиты: макс. открытый риск, дневной/недельный лимит убытка, макс. сделок в день.
2. Понимать корреляцию: лонг BTC + ETH + SOL ≈ одна большая ставка.
3. Встроить лимиты в торговый план.

## Ключевые тезисы
- Пример лимитов курса: ≤ 1% на сделку, ≤ 3% суммарного открытого риска, −3% за день → стоп торговли до завтра, −6% за неделю → стоп до понедельника и разбор.
- Корреляция альтов с BTC высокая → 3 лонга по 1% ≈ 3% на одну идею.
- Перенос стопа в безубыток уменьшает открытый риск (m11-l03).

## Визуалы
- Diagram `correlated-risk`.
- Checklist «Мои лимиты» (сохраняется, попадёт в торговый план m10-l03).

## Идеи вопросов теста
- [numeric] 3 позиции по 1% → суммарный открытый риск (3).
- [single] Почему лонг BTC и ETH одновременно — повышенный риск.
- [single] Что делать при достижении дневного лимита.
- [truefalse] Лимиты нужны только новичкам — неверно.
- [multi] Виды лимитов.
- [single] Как уменьшить открытый риск по позиции.
- [single] Недельный лимит курса.
- [single] Что такое корреляция.
