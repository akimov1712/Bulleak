# m05-l03 · RSI

- **Модуль:** 5   **Время:** ~11 мин   **Практика:** CandleChart + RSI
- **Статус:** ☑ бриф ☑ текст ☑ визуалы ☑ тест ☑ проверен в браузере

## Цели
1. Понимать, что показывает RSI (0–100) и классические уровни 70/30.
2. Знать, почему «перекуплен → продавай» — ошибка в тренде.
3. Использовать RSI для оценки импульса и зон 40–50 / 50–60 в тренде.

## Ключевые тезисы
- RSI(14) сравнивает средние росты и падения.
- В сильном аптренде RSI может неделями быть > 70.
- В аптренде RSI часто держится выше 40; откат к 40–50 — зона интереса.
- Дивергенции — m06-l05.

## Визуалы
- CandleChart `BTCUSDT-D` + RSI-панель; подсветка периода, где RSI > 70 долго, а цена росла.

## Идеи вопросов теста
- [single] Диапазон RSI.
- [truefalse] RSI > 70 — всегда сигнал на шорт — неверно.
- [single] Период RSI по умолчанию (14).
- [single] Поведение RSI в сильном аптренде.
- [chart-click] Где RSI вошёл в зону перепроданности.
- [single] Как курс предлагает использовать RSI.
- [multi] Чем опасна торговля «перекуплен-перепродан».
- [single] Что сравнивает RSI.
