# m07-l01 · Новости, макро и экономический календарь

- **Модуль:** 7 Фундаментал и контекст   **Время:** ~11 мин   **Практика:** Checklist
- **Статус:** ☑ бриф ☐ текст ☐ визуалы ☐ тест ☐ проверен в браузере

## Цели
1. Знать ключевые макрособытия, влияющие на крипту: решения ФРС по ставке, CPI, NFP.
2. Пользоваться экономическим календарём и не открывать сделки перед важными событиями.
3. Понимать крипто-специфичные новости: ETF, регуляторика, взломы, листинги.

## Ключевые тезисы
- Крипта реагирует на ликвидность в долларовой системе: ставки, инфляция, риск-аппетит.
- Перед FOMC/CPI волатильность растёт, спреды расширяются, стопы проскальзывают.
- Правило курса: не открывать новые сделки за N часов до событий высокой важности (N зафиксирует стратегия).
- «Покупай на слухах, продавай на фактах».
- Источники: экономический календарь (Investing.com / Forex Factory), официальные анонсы Bybit, крупные новостные сайты.
