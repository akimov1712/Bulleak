# Маршруты

`HashRouter` — URL вида `/#/lesson/m03-l02`. Все страницы, кроме главной и карты, — `React.lazy`.

| Путь | Страница | Описание |
|---|---|---|
| `/` | HomePage | Приветствие, «Продолжить обучение», цель дня, стрик, уровень, последние достижения |
| `/path` | PathPage | Карта пути (все модули и уроки) |
| `/module/:moduleId` | ModulePage | Обложка модуля, список уроков, экзамен |
| `/lesson/:lessonId` | LessonPage | Плеер урока |
| `/lesson/:lessonId/quiz` | QuizPage | Тест урока |
| `/exam/:moduleId` | ExamPage | Экзамен модуля; `/exam/final` — финальный |
| `/simulator` | SimulatorPage | Свободный режим тренажёра + список сценариев |
| `/simulator/:scenarioId` | SimulatorPage | Конкретный сценарий |
| `/tools` | ToolsPage | Список калькуляторов |
| `/tools/:calcId` | ToolsPage | Конкретный калькулятор (`position`, `liquidation`, `rr`, `expectancy`, `fees`, `drawdown`) |
| `/journal` | JournalPage | Список сделок + метрики |
| `/journal/new`, `/journal/:id` | JournalEntryPage | Создание / редактирование сделки |
| `/glossary` | GlossaryPage | Поиск по терминам; `/glossary/:termId` — открыт термин |
| `/cheatsheets` | CheatsheetsPage | Шпаргалки и чек-лист перед сделкой |
| `/stats` | StatsPage | Статистика |
| `/achievements` | AchievementsPage | Все достижения |
| `/settings` | SettingsPage | Тема, цель дня, экспорт/импорт, сброс |
| `/certificate` | CertificatePage | Сертификат (доступен после финального экзамена) |
| `/plan` | PlanPage | Торговый план, стратегия, проверка готовности (T-611, T-820) |
| `/about` | AboutPage | О курсе, дисклеймер, атрибуции и лицензии |
| `/dev/ui` | DevUiPage | Витрина UI-кита, только в dev-сборке |
| `*` | NotFoundPage | 404 с маскотом |

## Навигация
- Десктоп (≥ 1024px): левый сайдбар — Главная, Путь, Тренажёр, Инструменты, Журнал, Глоссарий, Статистика, Достижения; внизу Настройки. Сверху справа — стрик, XP, уровень.
- Мобильный: нижняя панель из 5 пунктов (Главная, Путь, Тренажёр, Журнал, Ещё), «Ещё» открывает лист с остальными разделами.
- Переход на заблокированный урок по прямой ссылке → экран «Урок пока закрыт» с кнопкой к доступному уроку (или открыть при `freeMode`).
- Скролл наверх при смене маршрута, сохранение позиции чтения урока.
