# Дизайн-система

**Стиль: яркий, игровой** (вдохновение — Duolingo, Brilliant), но с «торговым» характером: зелёный = бык/рост, красный = медведь/падение. Собственная палитра и формы — не копируем чужой бренд.

## Характер
- Крупные скруглённые карточки (radius 16–24px), «объёмные» кнопки с нижней тенью-бортиком (3D-press эффект при нажатии).
- Яркие цвета модулей, много воздуха, иллюстрации и маскот.
- Микроанимации: прогресс-бары заполняются плавно, XP «вылетает» числом, конфетти за тест, «подпрыгивание» узлов карты.
- Цифры (цены, P&L, проценты) — моноширинным шрифтом.

## Шрифты
- UI: **Nunito Variable** (округлый, хорошая кириллица). Заголовки 800, текст 500–600.
- Числа: **JetBrains Mono Variable** (`font-mono tabular-nums`).
- Размеры: текст урока 18px / 1.7 на десктопе, 17px на мобильном; ширина колонки текста ≤ 70ch.

## Базовые компоненты (`components/ui`)
Button (variants: primary, secondary, ghost, danger, xp; size: sm/md/lg; 3D-эффект), IconButton, Card, Badge, Pill, ProgressBar (линейный), ProgressRing (круговой), Modal/Sheet, Tabs, Input, NumberInput (с единицами и шагом), Select, Switch, Tooltip, Popover, Toast, Skeleton, EmptyState (с маскотом), Kbd.

## Маскот — «Бычок Буллик»
SVG-персонаж (милый бычок в кепке с графиком). Состояния: `happy`, `thinking`, `cheering` (праздник), `sad` (провал теста — поддерживающий, не стыдящий), `sleeping` (пустые состояния / сон стрика), `pointing` (подсказки), `shocked` (предупреждения о риске). Реализация — один React-компонент `Mascot` с пропом `mood`, части (глаза/рот/руки) меняются; лёгкая анимация дыхания (отключается при reduced motion).

## Темы
`data-theme="light|dark"` на `<html>`, по умолчанию — системная. Переключатель в TopBar и в настройках. Графики lightweight-charts получают цвета из токенов и перерисовываются при смене темы.

## Звук (опционально, по умолчанию выкл.)
Короткие звуки верного/неверного ответа и level up через WebAudio (генерируемые тоны, без файлов).
