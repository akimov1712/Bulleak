# Дизайн-система

**Стиль «Терминал»** (редизайн 2026-10-30, выбор пользователя): спокойный графитовый интерфейс торгового продукта, один фирменный зелёный акцент, геймификация — аккуратными деталями, а не яркими плашками. Зелёный = бык/рост, красный = медведь/падение. Собственная палитра и формы — не копируем чужой бренд.

## Характер
- Плоские карточки с тонкой рамкой `border` (radius 14px), без «объёмных» теней; кнопки плоские (radius 10px), нажатие — лёгкое уменьшение `scale(0.98)`.
- Тёмная тема по умолчанию; светлая — такая же сдержанная (белые карточки на светло-сером фоне).
- Цвета модулей — только как небольшие акценты (иконки, точки, полосы прогресса), не как заливки крупных блоков.
- Микроанимации: прогресс-бары заполняются плавно, XP «вылетает» числом, конфетти за тест.
- Цифры (цены, P&L, проценты, XP) — моноширинным шрифтом.

## Бренд
- Название — **Bulleak**, подпись — «Трейдинг на Bybit с нуля» (название курса). Константы — `src/app/brand.ts`.
- Знак — голова быка из свечи: тело свечи — голова, фитиль, два рога; белый на плитке с зелёным градиентом `#34E08A → #0A8A47` (радиус 16 из 64). Цвета знака одинаковы в обеих темах, как у любого логотипа, и живут только в `src/components/brand/mark.ts` — это единственное исключение из правила «цвета только токенами».
- Словесный знак: Inter 700, трекинг −0.035em, «Bull» цветом `bull`, «eak» — цветом текста.
- Из `mark.ts` собираются компонент `LogoMark`, `public/favicon.svg` и иконки PWA (`npx tsx scripts/gen-icons.ts`).
- Навигация (этап 12): сайдбар и мобильная шапка — тёмная панель `ink` (одинаковая в обеих темах: `ink`, `ink-2/3` для карточек и наведения, `on-ink`, `on-ink-muted`, акцент `ink-accent` = фирменный зелёный). Шапки на десктопе нет: профиль, уровень, серия, опыт и тема — в карточке наверху сайдбара. Разделы сгруппированы («Учёба», «Практика», «Прогресс»), иконки монохромные, активный раздел — зелёная заливка 12 % и полоска у края.
- Маскот Буллик — персонаж курса (подсказки, пустые состояния, празднования), в логотипе не используется.

## Шрифты
- UI: **Inter Variable** (нейтральный гротеск, хорошая кириллица). Заголовки 600–700, текст 400–500.
- Числа: **JetBrains Mono Variable** (`font-mono tabular-nums`).
- Размеры: текст урока 18px / 1.7 на десктопе, 17px на мобильном; ширина колонки текста ≤ 70ch.

## Базовые компоненты (`components/ui`)
Button (variants: primary, secondary, ghost, danger, xp; size: sm/md/lg; плоские), IconButton, Card, Badge, Pill, ProgressBar (линейный), ProgressRing (круговой), Modal/Sheet, Tabs, Input, NumberInput (с единицами и шагом), Select, Switch, Tooltip, Popover, Toast, Skeleton, EmptyState (с маскотом), Kbd.

## Маскот — «Бычок Буллик»
SVG-персонаж (милый бычок в кепке с графиком). Состояния: `happy`, `thinking`, `cheering` (праздник), `sad` (провал теста — поддерживающий, не стыдящий), `sleeping` (пустые состояния / сон стрика), `pointing` (подсказки), `shocked` (предупреждения о риске). Реализация — один React-компонент `Mascot` с пропом `mood`, части (глаза/рот/руки) меняются; лёгкая анимация дыхания (отключается при reduced motion).

## Темы
`data-theme="light|dark"` на `<html>`, по умолчанию — тёмная (можно выбрать светлую или системную). Переключатель в TopBar и в настройках. Графики lightweight-charts получают цвета из токенов и перерисовываются при смене темы.

## Звук (опционально, по умолчанию выкл.)
Короткие звуки верного/неверного ответа и level up через WebAudio (генерируемые тоны, без файлов).
