# Хостинг

## Сейчас
| Что | Где |
|---|---|
| Сайт (основной) | VPS в Москве: Ubuntu 22.04, 1 vCPU, 1 ГБ RAM, 15 ГБ NVMe, nginx. Пока открывается по IP, по HTTP |
| Сайт (старый адрес) | GitHub Pages, `akimov1712.github.io/Bulleak`, обновляется после зелёного CI |
| API | Ещё не выложен: нужны домен, HTTPS и вход на сайте (этап 14) |

IP сервера и доступы в репозиторий не записываются. Вход на сервер — только по SSH-ключу `~/.ssh/bulleak_deploy`, пароль отключён.

## Скрипты (`deploy/server`)
| Скрипт | Что делает |
|---|---|
| `harden.sh` | Обновления и автоматические обновления безопасности, вход только по ключу, файрвол (22, 80, 443) |
| `nginx.sh` | nginx: сайт из `/var/www/bulleak/current`, gzip, кэш для `/assets/`, без кэша для `index.html` и `sw.js`, заголовки безопасности |
| `release.sh` | Распаковывает новую версию в `releases/<время>`, переключает `current`, хранит три последние версии |

Выложить сайт с компьютера (PowerShell):
```
$env:BULLEAK_HOST = 'root@<ip>'
./scripts/deploy-vps.ps1
```
Откатить версию: на сервере переключить ссылку `current` на предыдущую папку в `releases`.
