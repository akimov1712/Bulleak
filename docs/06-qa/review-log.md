# Журнал код-ревью

После каждого этапа: `/code-review` по диффу этапа + ручной [чек-лист](../01-rules/code-review-checklist.md).

## Шаблон записи
```
## Этап XX — дата
- Диапазон: <commit>..<commit>
- Находок: N (исправлено M, отклонено K)
| # | Файл | Находка | Решение | Коммит |
- Ручной чек-лист: пройден / замечания
```
