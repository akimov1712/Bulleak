## Решения пользователя (2026-09-25)
- Хранение только в браузере (localStorage + IndexedDB), экспорт/импорт JSON.
- ~60 уроков (62), все интерактивные фичи: тренажёр, калькуляторы, журнал, глоссарий.
- Картинки: свои SVG, живые графики, фото из любых источников (сайт личный). Скриншотов Bybit нет — вместо них SVG-макеты интерфейса (уточнение 2026-09-25).
- Node обновлён до 24 LTS (по просьбе пользователя).
- Основной стиль — свинг (1H/4H/1D).
- Дизайн — яркий игровой.
- Публикация — GitHub + GitHub Pages.
- Работа по этапам с демонстрацией после каждого.

## Отклонения от исходного плана
- Загрузка свечей и компонент графика перенесены с этапа «тренажёр» на этап 04: они нужны уже урокам модуля 3.
- Node 20.13 → 24.19 LTS; инструменты на актуальных версиях (Vite 8, Vitest 5).
